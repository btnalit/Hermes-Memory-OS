## Purpose

This document maps existing Hermes subsystems into reusable Memory-OS modules.
The goal is to make a blank Hermes host installable with the same higher-level
agent architecture, without copying production-specific assumptions.

## Porting Rules

- Prefer adapters over direct path assumptions.
- Keep no-send mode as the default for all expression/delivery modules.
- Keep owner approval as the boundary for crystallized records.
- Keep identity writes out of module runtime.
- Keep Hindsight as optional adapter only.

## Sannai Boundary

Sannai-specific heartbeat, diary, identity, owner review, and curation surfaces
are not public module targets. They remain private. Memory-OS modules should be
compatible with her profile separation and approval boundaries, but they should
not package her private behavior.
