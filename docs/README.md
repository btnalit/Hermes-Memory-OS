# Memory-OS Docs

These are the public operator docs for the open-source Memory-OS project.

- [Quickstart](quickstart.md): install and verify Memory-OS on an existing
  Hermes profile.
- [Configuration](configuration.md): installer presets, cron onboarding,
  runtime loops, and validation commands.
- [V3 inner-life runbook](V3_INNER_LIFE_RUNBOOK.md): private journal,
  no-session inference, rollout gates, retention, and outlet boundaries.
- Current engineering status is tracked in the repository root:
  `V1_CURRENT_BASELINE.md`, `V1_STABILIZATION_PLAN.md`,
  `TECH_DEBT_REPORT.md`, `CODEX_TASKS.md`, and `RISK_REGISTER.md`.

Internal design notes and validation history are kept out of the public upload.
They are not required for installation or normal operation.
